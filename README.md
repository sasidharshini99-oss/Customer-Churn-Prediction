# Customer-Churn-Prediction
A machine learning project that predicts which telecom customers are likely to leave.  Data: 64,374 customer records, 12 features Models: Logistic Regression, Random Forest, SVM Best result: SVM with about 83% accuracy App: Tkinter GUI for live churn predictions  Tech: Python · Pandas · Scikit-learn · Matplotlib · Seaborn · Plotly · Tkinter
